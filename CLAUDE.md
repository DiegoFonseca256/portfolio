## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. They're recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

All domain docs sit at the repo root: one `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.
